## shiyi-photo-ai
## 拾忆影绘 AI 摄影推荐助手

## 一、项目简介

本项目面向有摄影需求的校园用户，围绕摄影套餐选择和预算匹配场景，开发了一个基于 Streamlit 的摄影推荐助手原型。

用户可以选择摄影类型并输入预算，系统根据预设的套餐数据和业务规则，返回相应的推荐结果、预算差额及费用提示。

当前版本说明：当前原型采用基于规则的推荐逻辑，尚未接入大语言模型，不应将其描述为已经实现大模型驱动的智能推荐。

## 二、项目目标

- 降低用户筛选摄影套餐的成本。
- 根据用户预算判断套餐是否符合预算要求。
- 对最低消费和额外费用等业务规则进行提示。
- 通过自动化测试和页面验收检查推荐功能。

## 三、主要功能

1. 摄影套餐数据管理。
2. 摄影类型与预算输入。
3. 套餐推荐与预算匹配。
4. 超预算金额和剩余预算计算。
5. 校园跟拍最低消费规则处理。
6. 天津跟拍交通及门票额外费用提示。
7. 自动化测试与页面功能验收。

## 六、运行方法

在项目终端中安装依赖：

```bash
python -m pip install -r requirements.txt
```

启动应用：

```bash
python -m streamlit run app.py --server.address 0.0.0.0
```

运行自动化测试：

```bash
python -m pytest -v test_recommend.py
```

## 七、测试与验收

自动化测试覆盖以下场景：

- 单人写真预算不足。
- 单人写真预算充足。
- 双人写真预算充足。
- 校园跟拍最低消费规则。
- 天津跟拍额外费用提示。
- 预算恰好等于套餐价格。
- 负数预算异常处理。

页面验收围绕摄影类型选择、预算输入、推荐结果展示及费用提示展开。

具体测试通过数量、页面验收结果和缺陷修复情况，以实际运行记录为准。

## 八、当前版本的局限

- 推荐逻辑基于预设规则，尚未接入大语言模型。
- 推荐效果依赖套餐数据的准确性与完整性。
- 未经确认的服务内容和费用不应作为确定承诺。
- 当前版本仍需根据真实用户反馈继续迭代。

## 九、后续迭代方向

- 优化页面交互与结果展示。
- 补充更多边界场景和异常输入测试。
- 收集用户反馈，完善摄影套餐数据。
- 在业务需求明确、数据准备充分后，再评估是否接入大语言模型。
